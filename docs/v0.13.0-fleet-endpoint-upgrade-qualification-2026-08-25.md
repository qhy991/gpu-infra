## Ownership contract

The original fleet catalog and route receipt remain the sole owners of:

- route-time node selection and capability decision;
- immutable node id and `(node_id, run_id)` locator;
- node-owned inbox and bundle path;
- task, candidate, and accepted run identity.

`kernelinfra.fleet-endpoints.v1` owns only current reachability:

- SSH host;
- installed kernelctl path;
- daemon socket.

The map may contain only node ids already present in the historical catalog. It
cannot be used for submit or a bare locator and cannot replace inbox,
capability, node id, task, candidate, or run facts. It adds no digest. Every v2
observation, snapshot, and mirror embeds the exact endpoint values actually
used.

Status, wait, and snapshot validate returned run/task/candidate and recorded
run-directory identity. Frontier performs the same status continuity check
before rebuilding from the historical inbox. Artifact install validates the
manifest identity and run directory. Route cancellation sends all expected
identity values to the daemon in one checked operation, so validation and
cancellation share one authority boundary without a client-side race.
