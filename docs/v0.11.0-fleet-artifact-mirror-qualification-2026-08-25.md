## Contract

The node-side `kernelinfra.artifact-manifest.v1` is owned by one terminal run
directory. It records the route-relevant run/task/candidate identity, terminal
state/time, normalized regular-file inventory, sizes, and one aggregate
artifact-set transfer digest.

The receiver rejects nonterminal exports, absolute/traversing paths, links,
devices, duplicate members, a late/missing manifest, unexpected or missing
files, truncation, byte/file-count limits, size drift, content drift, route
identity drift, and an existing destination. A successful install contains:

```text
catalog.json
route.json
artifact-manifest.json
mirror.json
artifacts/
```

`kernelinfra.artifact-mirror.v1` says `authority=mirror-only` and
`validation=passed`. It cannot supply status, routing load, cancellation,
correctness, or frontier decisions; those remain node-owned.

Following the project SHA-256 restriction, this feature adds no per-file,
manifest, or mirror digests. One aggregate digest remains because it is the
cross-machine integrity boundary and a mismatch changes the action from install
to reject. Existing catalog, route, task, and candidate identities are reused.
