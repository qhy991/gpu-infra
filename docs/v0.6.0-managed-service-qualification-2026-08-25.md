## Remaining boundary

Managed lifecycle no longer requires tmux, but task materialization still
requires binding a ready deployment's generated identity and receipt path into
the immutable task contract. Kernel Infra also has no idle-time/reference-count
campaign policy; stop remains an explicit user/agent action. Cross-host routing,
hostile multi-tenancy, priorities/preemption, and live-command recovery remain
out of scope.
